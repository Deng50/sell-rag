## 项目功能与覆盖范围

项目是 Windows 单机售卖终端的多模态 RAG 服务：文档/商品摄取、版本与 ACL 管理、SQLite 精确商品查询、按角色隔离的混合检索、引用回答、FastAPI/CLI/PyQt、百度语音、人员存在检测以及回归评测。默认 Fake 模式能离线运行；生产适配器依赖外部密钥、模型和设备。

本轮逐文件阅读全部 28 个生产 Python 文件（包括各包初始化文件）、原有测试和夹具、README、pyproject.toml、requirements.lock、默认 YAML、环境示例与 Git 忽略规则。审查涵盖存储、数据契约、摄取、切片、索引、查询、生成、接口、CLI、语音、摄像头、UI、日志与评测；修复后共有 8 个测试 Python 文件。未将 `.venv`、第三方包、生成的运行数据当成项目源码。

## 实现边界与需要外部验收的能力

- 云端智谱/百度、真实 ASR/TTS、GPU BGE/Cross-Encoder、FAISS、麦克风/摄像头/YOLO、扫描 PDF OCR 及完整 Docling 模型链路未做实机验收。Docling 结构处理有适配层模拟测试；DOCX 使用真实轻量解析库测试。这些不能表述为“已验证生产可用”。
- Fake 生成、哈希 Embedding、词项重排、静音 WAV 都是离线演示实现。需配置真实服务才能获得真实语音/语义能力；SSE 当前是生成完成后的分段传输，上游模型首 Token 实时流式生成尚未实现。
- 引用校验检查引用编号是否来自检索证据，不等价于逐句事实蕴含验证。未标注的内置评测集不能给出真实检索准确率；现在相应指标返回 null。
- 本次修复前数据库没有保存完整商品历史，不能凭空恢复已丢失的历史价格/库存。迁移保留可用快照，缺失快照的回滚会明确失败；重新摄取原始历史文件可建立新快照。新增版本已经完整保存。
- API 管理发布保证数据库文档/商品/索引版本共同切换。底层 `IngestionService.ingest` 的默认立即激活仍保留供本地编程调用；需要发布保证时应使用 CLI/API，或传 `activate=False` 后调用 `index.build(changes)`。
- 本轮运行出现 Starlette 对 httpx 测试适配器的弃用提示，不影响断言结果。Ruff 执行的是错误级规则集，未把现有仓库的所有风格提示清零。
- 全量阅读与回归测试不能证明不存在任何潜在 bug；以上列出已确认修复和已验证范围，没有把外部能力当作测试通过。
